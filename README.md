# 🔫 Gunfire: Waves & Bosses

A top-down wave shooter that runs in the browser. Survive waves, earn coins, buy gun upgrades, and beat a boss every 5th wave.

## Play
Open `index.html` in any browser, or host it free with GitHub Pages.

## Controls
- **Move:** WASD / arrow keys
- **Aim:** mouse
- **Shoot:** hold left click
- **Next wave (in shop):** button or Space

## Features
- Endless waves with 3 enemy types that scale in difficulty
- Boss wave every 5 waves (bullet rings + aimed shots)
- Upgrade shop: damage, fire rate, multishot, max HP, speed, heal

## Deploy on GitHub Pages
1. Create a new repo and upload `index.html` and `README.md`
2. Go to **Settings → Pages**
3. Under **Source**, pick the `main` branch and `/ (root)`, then Save
4. Your game goes live at `https://<your-username>.github.io/<repo-name>/`
